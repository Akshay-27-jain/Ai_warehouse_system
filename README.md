# AI Warehouse Optimization System

This repository contains the proposed architecture and folder structure for an enterprise-grade AI warehouse optimization platform.

## Structure Overview
- apps/web: React 19 + Vite + TypeScript frontend
- services/api: Flask + SQLAlchemy backend
- services/worker: background job worker
- services/ai: ML training and inference modules
- infra: Docker, Compose, and Nginx configuration
- docs: architecture and operational documentation
